# Nihongo-Learn

## 需求
我想要做个动词变形表的web，分为规则讲解和练习两部分，用顶部标签来切换
首先是规则讲解的部分；
1.列为 动词类型（第 I 类动词/五段动词，第 II 类动词/一段动词,か变，さ变，说明)这种,可能有遗漏，继续补足
2.说明列为 说明当前行的词型 比如（未然形 (みぜんけい)行：（接续否定「ない」、意志「う/よう」、使役、被动））
3.行为 活用型（未然形 (みぜんけい)，连用形 (れんようけい)，	终止形 (しゅうしけい)，连体形 (れんたいけい)，假定形 (かていけい)，命令形 (めいれいけい)）这种变形，可能有遗漏，继续补足
4.行和列组合起来就是 变化规则 （	未然形+第 I 类动词/五段动词：词尾「う」段音变为「あ」段音）
5.表格里的卡片可以翻转，点击翻转，显示出当前变化规则对应的例子

然后是练习的部分：
基于基本规则的表格，随机给出其中一个单词，然后入力填入他的每行所对应的变形后的词，这样进行练习
有两种模式
1.简易模式
给出几种选项，用户选择回答，模糊选项为同词的不同变形
2.标准模式
让用户输入回答
