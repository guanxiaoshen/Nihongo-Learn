# Nihongo-Learn 规则图谱项目管理与迭代计划

> 版本：规则图谱 v2
> 更新日期：2026-08-28
> 适用范围：动词变形、形容词/副词/名词相关变形规则的呈现与记忆辅助

产品定位、记忆原则和后续模块扩展方式以 [`产品理念与扩展规范.md`](./产品理念与扩展规范.md) 为长期参考；本文档负责具体里程碑、进度和验收。

## 一、项目定位

Nihongo-Learn 不是完整的课程平台，也不是以打卡、统计或每日任务为核心的学习管理系统。产品的核心是：

> 把日语变形规则讲清楚、展示清楚，并帮助观看者记住“怎么变、接什么、表达什么、有什么例外”。

练习只承担即时回忆和自我检查的作用，不单独发展为复杂的题库、计划或社交功能。

## 二、产品边界

### 当前范围

- 动词：五段、一段、来る、する/复合する；
- 动词的基础形、常用派生形、条件、语态和敬语/谦让表达；
- い形容词、な形容词、名词的基本变化；
- 形容词和名词在定语、副词等句中功能上的使用说明；
- 高频例外、易混形式和对比例句；
- 规则区块后的 1–3 道轻量回忆题；
- 保持纯静态、零框架、可在 `file://` 环境运行。

### 当前不做

- “今日学习”首页、每日任务和连续打卡；
- 账号、云端同步和跨设备学习档案；
- 将正确率、错题队列扩展成独立的复习产品；
- 为了增加内容而无限扩展活用行；
- 在规则图谱完成前优先投入更多主题样式。

已有的 `localStorage` 统计和独立练习面板可以保留，作为兼容和辅助能力，但不能反过来决定规则页面的信息架构。

## 三、学习目标与设计原则

### 学习者看完一个规则后应能回答四个问题

1. 从什么形式开始？
2. 哪一部分发生了变化？
3. 后面接什么？
4. 这个形式在句子中表达什么？

### 展示原则

1. **先展示变化操作，再展示语法术语**：术语保留，但不能遮住“去掉什么、替换什么、接什么”。
2. **一个代表词贯穿一组规则**：例如用 `書く` 展示 `書かない、書きます、書いて、書いた、書けば、書こう`。
3. **按可记忆的模式分组**：五段音段、て/た 音便、否定、条件、语态等，而不是让 25 行内容平铺竞争注意力。
4. **过程和结果同时可见**：使用“词干/变化部分/接续”三段式视觉分层。
5. **例外放在对应规则旁边**：`行く`、`いい`、`する → できる` 等不能只放在页面底部。
6. **理解后立即回忆**：每个规则块后设置小题，先遮住结果，再显示答案和解释。
7. **类型标注明确统一**：规则表、记忆卡和练习选项统一写明“一类･五段动词、二类･一段动词、三类･カ变动词、三类･サ变动词”。
8. **四类都能展开理解**：用标签切换详细内容，不能只展示五段而把二类/一段和三类动词压缩成一句摘要。

## 四、目标信息架构

### 4.1 动词规则页

默认学习路径：

```text
选择动词类型
  ↓
一眼记忆卡
  ↓
基础常用形
  ↓
て形/た形音便
  ↓
按用途查看派生形
  ↓
例外与易混辨析
  ↓
规则块后的轻量回忆题
  ↓
完整 25 形查询表
```

#### 五段动词的中心记忆图

页面应优先展示五个音段和典型接续：

```text
あ段：ない、被动、使役等
い段：ます、たい等
う段：辞书形、终止形
え段：ば、命令、可能等
お段：う（意志形）
```

同时明确 `う → わ` 的未然形特殊变化。

#### て形/た形音便

将音便做成按词尾分组的记忆图：

```text
う・つ・る → って／った
ぬ・ぶ・む → んで／んだ
く         → いて／いた
ぐ         → いで／いだ
す         → して／した
行く       → 行って／行った（例外）
```

#### 复杂派生形

建议按用途而不是按行号组织：

- 日常常用：辞书形、ます形、ない形、て形、た形；
- 愿望与条件：たい、意志、ば、たら、なら；
- 语态：可能、被动、使役、使役被动；
- 否定连接与禁止：なくて、ないで、禁止；
- 敬语与固定表达：尊敬、谦让。

完整 25 形仍然保留，作为查询层而不是默认的第一记忆层。

### 4.2 形容词、名词与副词用法页面

先展示两条核心公式：

```text
い形容词：
去「い」＋くない／かった／くて
条件：去「い」＋ければ

な形容词/名词：
词干＋だ／じゃない／だった／で／なら
```

随后分开讲述：

- 谓语的肯定、否定、过去和条件变化；
- い形容词作定语和副词的形式；
- な形容词作定语时的「な」、作副词时的「に」；
- 名词的「の」等定语连接和相关句型。

副词应作为“句中功能”展示，不能和动词、形容词、名词一起被误解为同一种活用类别。

## 五、统一规则区块

每个规则区块建议具备以下内容：

```text
规则标题
学习者语言的用途说明
语法术语（辅助）
起点
变化公式
颜色分层的变形结果
代表例句
易错点/例外
1–3 道回忆题
```

推荐使用统一的语义颜色：

```text
保留部分：墨色
变化部分：主题色
接续后缀：辅助强调色
例外：橙色或独立警示色
用途说明：说明色
```

颜色只表达信息层级，不能依赖颜色作为唯一辨别方式；文字、符号和结构必须同时存在。

## 八、验收标准

### 记忆呈现

- 学习者进入动词页面后，能先看到四类动词标签和当前类型的核心变化，而不是直接面对 25 行密集内容；
- 学习者可以通过四类标签分别查看一类･五段动词、二类･一段动词、三类･カ变动词、三类･サ变动词的详细六种常用变化；
- 选择不同类型标签后，派生形用途区会同步显示该类型的实际结果；
- 用 `書く` 可以沿一条路径看懂 `書かない、書きます、書いて、書いた、書けば、書こう`；
- て形/た形的分组口诀、代表词和 `行く` 例外位于同一学习区块；
- 每条规则都能看见起点、变化部分、接续和用途；
- 术语不会取代实际变化过程。

### 内容完整性

- 25 个动词形式仍可查询；
- 五段、一段、来る、する的规则和例外不减少；
- 形容词/名词的六种基础变化保留；
- 副词和定语用法与基本谓语变化分开说明；
- `いい`、`きれい`、可能/被动等易错点有就地提示。

### 练习边界

- 练习紧跟规则区块，每块原则上 1–3 题；
- 练习服务于回忆规则，不引入每日任务或复杂学习计划；
- 错误后能看到正确结果和简短原因；
- 现有页面的基础练习能力不因重构规则展示而失效。

### 工程稳定性

- 继续支持零依赖、纯静态和 `file://` 运行；
- 不改变现有数据外置和变形引擎的职责；
- 完成后运行仓库已有的验证脚本；
- 只在对应里程碑提交代码和文档变更。
