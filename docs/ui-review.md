# Nihongo-Learn · UI 系统性审查报告

> 审查人：UI Designer　日期：2026-08-25　范围：index.html / verb-conjugation-stamp.html / adj-noun-stamp.html

> 全站风格统一：首页与两个学习页采用同一纸面纹理、键盘焦点、音变速查表表头/行悬停和间距语言；形容词/名词页的速查区外框与动词页保持同源。
> 五段音变表的结果单元格增加“代表词例 + 振假名 + 变形结果”，并统一表头、居中对齐和移动端横向滚动体验；形容词/名词速查表补齐“词类”表头以保持列对齐。

## 一、配色与对比度（WCAG AA）— 问题最集中

> 实测 5 套主题 × 常用前景/背景组合，**11 项不达标**。次要文字是重灾区。

| # | 严重度 | 组合 | 实测 | 要求 | 位置 |
|---|---|---|---|---|---|
| C1 | 🔴 高 | `--muted` on `--paper`（#806e68/#f6f3ee） | **4.36:1** | 4.5 | 全站说明文字：面板 intro、卡片 note、练习说明 |
| C2 | 🔴 高 | `--muted` on `--wash`（#806e68/#f0ece6） | **4.10:1** | 4.5 | intro-note、速记、工具条说明 |
| C3 | 🔴 高 | `--accent-muted` on `--surface`（#9b8978/#fffdfa） | **3.31:1** | 4.5 | 首页卡片 footer、页脚、卡片 footer 提示 |
| C4 | 🟠 中 | `--success` on `--success-soft`（#4b8068/#e4f0e7） | **3.91:1** | 4.5 | "现在可学/正确"徽标小字 |
| C5 | 🟠 中 | `--danger` on `--danger-soft`（#a75550/#f6e3e0） | **4.18:1** | 4.5 | 练习错误提示 |
| C6 | 🟡 低 | 白字 on `--vermilion`（#ffffff/#b9655b） | 4.14:1 | 大字号 3.0 ✓ | 印章大字通过；若用于小字需注意 |

**主题扩展性**：墨流/苔庭/蓝染/藤棚 四套的 `--muted` on paper 实测 3.86–4.22:1，**全部不达标**——不是单主题问题，是 muted 基准色整体偏浅。

**修复建议**：将 `--muted` 加深一档（如默认主题 #6b5b56，并让各主题 muted 对齐 ≥4.6:1）；`--accent-muted` 加深至 #8a7766 左右；success/danger 各加深一档。改 themes.css 一处即可全站生效（这正是 token 化的价值）。

## 三、交互反馈与状态

| # | 严重度 | 问题 | 位置 | 建议 |
|---|---|---|---|---|
| F1 | 🔴 高 | **键盘焦点几乎不可见**：primary/secondary/type-chip/mode-button/theme-option/count-select 均无 `:focus-visible`（verb/adj 页各仅 2 处） | 全部按钮 | 全局统一 `:focus-visible { outline: 3px solid var(--vermilion); outline-offset: 3px; }`，与现有链接焦点风格对齐 |
| F2 | 🟠 中 | `secondary-button` 无通用 `:disabled` 样式（仅 start-actions 特例）；radio/select 焦点依赖浏览器默认 | 按钮/表单 | 补 `.secondary-button:disabled` + select/radio 的 focus 样式 |
| F3 | 🟡 低 | 主题面板只能点按钮开合，**无 ESC / 外点关闭**；键盘进入菜单后缺少方向键支持 | css/themes.css | 补 ESC 关闭 + `role="menu"` 的方向键导航（或降级为简单 dialog 语义） |
| F4 | 🟡 低 | 卡片翻转有延迟级联动画（--card-delay），但无 hover 微反馈 | 规则卡片 | 可选：正面加"悬停微抬升"；不必强求 |
